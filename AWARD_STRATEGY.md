# Award strategy — reviewed October 25, 2026

Goal: maximize the chance of at least one officially recognized award, without a guarantee or fabricated probability.

The official prize list includes 10 Most Valuable Feedback awards, one Coding and Agentic Engineering track award, and one Tavily award. No universal participation prize appears in the published prize table. Devpost participation achievements are not equivalent to a judged competition award. Feedback and Tavily are Bonus awards; the stacking restrictions still apply. [Official rules](https://nebiusglobalaihackathon.devpost.com/rules)

No calibrated winning percentage is supportable. Total registrations are not the number of eligible final projects or feedback entries, and judging is not a random draw. The current build has no real Nebius/NVIDIA runtime evidence, so its eligibility is not established. Improving an ineligible entry's polish does not solve that gate.

## Highest-priority next evidence

1. Obtain legitimate Nebius access and execute a real NVIDIA Nemotron call through Token Factory. Record exact model, endpoint, parameters and response provenance.
2. Run the bounded lab and generated-case workflow. Preserve successful and failed trials. Select a small number of repeated developer-impacting observations; investigate whether they are documented limits, request mistakes, model variability, SDK defects or platform issues.
3. Use `patchcourt feedback` to assemble raw counts, qualified uncertainty, reproductions, recommendations and acceptance tests. Human-review every claim. Do not manufacture negative findings; positive results can be useful if specific and actionable.
4. Connect observations to executable regression contracts and scoped knowledge. Demonstrate a later run reusing those observations while independently verifying behavior.
5. If Tavily access is available, run the paired documentation experiment and identify a specific changed test/classification/recommendation. A token request or mere presence of citations is insufficient evidence of benefit.
6. Replace the offline video segment with real model and platform evidence, publish an under-three-minute YouTube video, and complete authenticated Devpost fields. Verify public build access and final submission approval.

The implemented optimization is an honest evidence-to-feedback pipeline, a tested downloadable offline build, and a genuine subtitled browser demo. It is not a claim that Feedback is easy to win or that additional features guarantee an award.

City awards require actual attendance at an eligible event. Attendance is unknown and must not be invented. Entrant identity/region/eligibility and final submission cannot be completed from API keys alone.
