# Competition audit

Checked 2026-10-24 (Asia/Shanghai) against public official pages. This is an evidence checklist, not confirmation that the entrant or current build is eligible. No entry was submitted and nobody was contacted.

## Rules that affect release decisions

The submission period starts August 26, 2026, 09:00 Pacific and ends October 30, 2026, 10:00 PDT: **October 31, 2026, 01:00 Asia/Shanghai**. Judging ends December 15, 2026, 12:00 Pacific; keep judge access available through then. Winners are expected around January 11, 2027.

An eligible project must use an NVIDIA open-source model and either call Token Factory at runtime or run on qualifying Nebius AI Cloud compute. Entrants must meet majority, residence, ownership, and conflict-of-interest conditions. Personal eligibility remains unverified.

Each project can receive one Overall award OR one Track award plus one Bonus award. Tavily requires a functional runtime API call. Feedback eligibility requires completing the submission feedback section; completeness, viability, and potential impact are its criteria. Feedback and Tavily are both Bonus categories: do not promise both prizes.

Provide judges free, unrestricted project access through judging. Supply credentials for a private demo. Materials require English or translations. Preserve third-party licenses. A potential award is not final until required verification completes. [Official rules, sections 1–8](https://nebiusglobalaihackathon.devpost.com/rules)

## Submission package

Public requirements confirm: working project; selected track; product description; working demo, hosted app, or test-build URL; public GitHub/GitLab/Bitbucket source; detectable open-source license; README setup/run instructions; explanation of NVIDIA/Nebius usage; feedback; and significant changes made during the competition for pre-existing projects. Prepare a public YouTube demo **under three minutes** to satisfy the stricter rules wording. The overview describes three minutes or shorter. ## Updates and onboarding

The official feedback guidance asks what each used platform/model did, strengths, weaknesses, onboarding experience, and whether the entrant would use it again, with reasons. It asks for explicit NVIDIA/Nebius attribution in the description, Built With section, and spoken video. Prepare balanced evidence and name exact products. [Feedback and packaging update](https://nebiusglobalaihackathon.devpost.com/updates/46205-how-to-build-a-winning-project)

The newest accessed judging recap recommends a fast demonstration of value, a focused product, visible model roles, documented limitations, and enough packaging time. This supports prioritizing one authentic, inspectable regression over a long feature list. [Judging recap](https://nebiusglobalaihackathon.devpost.com/updates/47163-recording-will-your-project-ship)

Nebius country-list onboarding gaps are distinct from hackathon exclusions. The FAQ expressly rejects using another billing region as a workaround. Calling an NVIDIA model through Token Factory can satisfy infrastructure requirements without hosting the entire frontend there. Promotional grants described there are Token Factory credits, not a separate published Cloud grant. Do not infer residence from the user's timezone. [Official FAQ](https://nebiusglobalaihackathon.devpost.com/details/faqs)
